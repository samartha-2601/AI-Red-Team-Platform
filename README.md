# AI Red Team Platform

An AI security platform that automatically evaluates Large Language Models (LLMs) for security vulnerabilities.

## Planned Features

- Prompt Injection Testing
- Prompt Leakage Detection
- Jailbreak Detection
- OWASP LLM Top 10 Mapping
- Multi-Model Testing
- Security Reporting
